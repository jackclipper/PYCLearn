# 北洋合唱团 · 十二天识谱计划

每天五分钟，把五线谱读成一句话。

为合唱新生设计的识谱练习网站。提供高音谱号主线、可选低音谱号支线和答错即结束的无尽模式。网站为纯前端应用，无需账户、数据库或后台服务。

## 功能

- **高音谱号主线**：6 天学习 + 6 天随机小测，小测依次为 20、22、24、26、28、30 题。
- **低音谱号支线**：3 天学习 + 第 4 天 20 题小测，进度独立保存。
- **小测音域**：高音 G3–B5（17 个自然音）；低音 E2–B3（12 个自然音）。每次小测均覆盖对应范围内的每个自然音。
- **无尽模式**：默认高音，可混入低音；错误即结束。记录单局最高连对和按真实日期计算的最长连续坚持天数。
- **自然日打卡**：当天第一次作答记录日期，同日重复挑战只计一天；日期使用访问设备的本地时区。
- **固定唱名**：do、re、mi、fa、sol、la、si，同时显示 C–B 音名。数字键 1–7 作答，课程中按 Enter 继续。
- **标准谱面**：VexFlow 生成 SVG，支持加线音和窄屏教学卡片。
- **本机记录与成绩卡**：保存课程进度、最好成绩、无尽纪录，课程结算可下载 PNG 打卡卡片。

本项目训练自然音识读，尚未包含升降号、调号、节奏或音准评分。所谓“天”是课程编号：完成一课即可解锁下一课，没有强制等待 24 小时。

## 本地运行

使用 **Node.js 22.13 或以上**，推荐 Node.js 22 LTS 的最新补丁版本。

```bash
npm ci
npm run dev
```

在浏览器打开终端打印的本地地址。首次安装也可用 `npm install`。

```bash
npm test          # 课程范围、题库覆盖、无尽题与自然日统计测试
npm run typecheck # TypeScript 检查
npm run build     # 类型检查并构建静态网站，输出 dist/
npm run preview   # 本地预览构建后的静态网站
```

本项目不需要 `.env` 或任何密钥。

## 源码结构

```text
src/
  main.tsx           React 挂载入口
  App.tsx            首页、谱面、课程训练、无尽模式、进度与成绩卡
  styles.css         暖白练习册视觉与移动端样式
  lib/
    training.ts      音符类型、课程配置、题库生成、日期统计
public/
  favicon.svg        站点图标
tests/
  training.test.mjs  核心规则测试
```

常见修改位置：

| 想修改什么                       | 修改位置                                                     |
| -------------------------------- | ------------------------------------------------------------ |
| 每天标题、提示、锚点、范围、题量 | `src/lib/training.ts` 的 `dayPlans` / `bassPlans`            |
| 小测及无尽模式音域               | `src/lib/training.ts` 的 `trebleQuizNotes` / `bassQuizNotes` |
| 谱号、音符横纵位置和 SVG 自适应  | `src/App.tsx` 的 `MusicStaff`                                |
| 首页、训练与结算界面             | `src/App.tsx`                                                |
| 颜色、字体、排版、响应式         | `src/styles.css`                                             |
| 标题、搜索摘要                   | `index.html`                                                 |

音高使用自然音级差：`step = 0` 对应 C4，向上每个自然音 +1、向下 -1；八度编号按 C4 为中央 C。当前高音题库从 -3 开始共 17 个音，低音题库从 -12 开始共 12 个音。修改题库时，应保证小测题量不小于对应题库大小，以保留“每音至少一次”的规则。学习日独立使用聚焦范围，不随小测音域自动扩张。

## 数据与隐私

所有进度仅保存在当前浏览器的 `localStorage`，键以 `beiyang-sightreading-` 开头。没有排行榜、跨设备同步或团长后台。清除站点数据会清空本机记录；隐私浏览可能无法长期保存。课程完成记录不包含未结算一局中的答题进度。

源码保留原站点的存储键和旧课程迁移逻辑。在**相同来源**下替换部署通常可继续读取记录；协议、域名或端口改变后，浏览器会把它视为不同来源，不会自动迁移数据。

## 来源与整理

这份项目基于原识谱网站取回的可读 TSX / CSS 源码整理，未从压缩 JavaScript 反编译。为方便独立开发与开源，移除了原项目中未使用的数据库、认证、Worker 和托管构建脚手架，改为标准 Vite 静态构建；课程数据和纯函数独立到 `src/lib/training.ts`。原先学习卡、小测及无尽模式的界面和业务逻辑保留。

本仓库不包含托管凭据、平台项目标识、用户进度、`node_modules` 或预构建产物。源码交付不自动更新已部署的网站。
